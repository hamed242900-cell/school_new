سامانه مدیریت مدرسه - نسخه توسعه یافته

امکانات:
1) ورود کاربران و سطح دسترسی: مدیر سیستم، کاربر مدرسه، فقط مشاهده
2) رمز عبور و اجبار تغییر رمز اولیه
3) ورود گروهی دانش آموزان از Excel + قالب آماده
4) پشتیبان گیری و بازیابی
5) گزارش گیری و چاپ
6) تاریخ هجری شمسی و فارسی در رابط و گزارش ها
7) ارتباط با WhatsApp، بله، روبیکا و ایتا از روی اطلاعات دانش آموز
8) حضور و غیاب و ثبت انضباط

ورود اولیه:
نام کاربری: admin
رمز: admin123

نصب در ویندوز:
Python 3.10+ نصب باشد و سپس «نصب و اجرای سامانه.bat» را اجرا کنید.


امکانات افزوده این نسخه:
- علامت‌گذاری و حذف دانش‌آموزان انتخاب‌شده یا حذف کلی نتایج فیلتر
- پیام گروهی بر اساس پایه و کلاس و انتخاب پدر، مادر، هر دو یا دانش‌آموز
- ثبت جداگانه شماره پدر و مادر
- ثبت تاریخ تولد شمسی، یادآوری تولد در داشبورد و تأیید مدیر برای آماده‌سازی پیام تبریک
- قالب Excel شامل شماره پدر، شماره مادر و تاریخ تولد

نکته پیام‌رسان‌ها: برای امنیت و رعایت محدودیت API پیام‌رسان‌ها، برنامه لینک گفت‌وگوی آماده می‌سازد و ارسال نهایی با تأیید کاربر در خود پیام‌رسان انجام می‌شود. برای ارسال کاملاً خودکار باید API رسمی و دسترسی/توکن مربوط به هر پیام‌رسان فراهم شود.


امکانات جدید این نسخه:
9) گزارش غیبت با بازه دلخواه، از یک هفته تا ابتدای سال تحصیلی و نمایش جزئیات هر دانش‌آموز
10) آزمون آنلاین با لینک اختصاصی، ورود با نام و کد ملی، یک‌بار شرکت برای هر دانش‌آموز، شماره تلفن اختیاری/اجباری توسط مدیر و تصحیح خودکار سؤالات چهارگزینه‌ای
11) کارنامه آزمون و امکان ارسال نتیجه از طریق واتساپ رسمی در صورت تنظیم API
12) ارسال گروهی خودکار واتساپ در صورت فعال‌سازی API رسمی؛ بله، ایتا و روبیکا ساختار شناسه/لینک دارند و برای ارسال خودکار نیازمند API رسمی و دسترسی مربوط به حساب هستند.
13) در صورت فعال بودن API واتساپ، پس از تأیید مدیر، تبریک تولد نیز می‌تواند خودکار ارسال شود.
