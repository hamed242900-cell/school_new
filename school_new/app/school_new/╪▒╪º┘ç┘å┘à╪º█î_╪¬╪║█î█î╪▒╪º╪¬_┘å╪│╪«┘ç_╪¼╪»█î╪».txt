نسخه جدید SchoolManagement - تغییرات

1) مشخصات دانش‌آموز:
- نام پدر
- شماره تماس دانش‌آموز، پدر و مادر
- شناسه/شماره هر یک از پیام‌رسان‌های واتساپ، بله، روبیکا و ایتا برای دانش‌آموز، پدر و مادر
- دکمه پیام مستقیم کنار اطلاعات هر مخاطب

2) پیام گروهی:
- همه / پایه / کلاس
- حالت «فقط دانش‌آموزان انتخاب‌شده»
- انتخاب چند دانش‌آموز با تیک
- گیرنده: پدر، مادر، هر دو، دانش‌آموز
- واتساپ، بله، روبیکا، ایتا
- متغیرهای {نام}، {نام پدر}، {پایه}، {کلاس}
- آماده‌سازی پیام‌ها و ارسال خودکار واتساپ در صورت تنظیم API رسمی
- ثبت نتیجه و تاریخچه ارسال
- نوار درصد موفقیت بعد از ارسال

3) دعوت‌نامه ولی:
- انتخاب چند دانش‌آموز
- عنوان، تاریخ شمسی، ساعت، مکان و متن دعوت‌نامه
- انتخاب پدر/مادر/هر دو
- آماده‌سازی لینک پیام در پیام‌رسان‌ها
- ارسال خودکار واتساپ در صورت تنظیم API رسمی
- چاپ دعوت‌نامه‌ها

4) Excel:
قالب Excel اکنون علاوه بر اطلاعات قبلی، ستون‌های جداگانه پیام‌رسان پدر و مادر را نیز پشتیبانی می‌کند.

توجه: برای ارسال کاملاً خودکار واتساپ، API رسمی WhatsApp Cloud API باید در تنظیم پیام‌رسان پیکربندی شود. برای بله، ایتا و روبیکا در این نسخه لینک/شناسه پیام‌رسان استفاده می‌شود تا API رسمی مربوطه به برنامه متصل شود.
