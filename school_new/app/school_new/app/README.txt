سامانه مدیریت مدرسه
===================

امکانات:
- مدیریت دانش‌آموزان و شماره تماس دانش‌آموز/ولی
- جستجو بر اساس نام، کد، کلاس و شماره تماس
- حضور و غیاب روزانه
- ثبت و حذف موارد انضباطی
- داشبورد آماری
- دیتابیس SQLite

اجرای ویندوز:
1) Python 3.10 یا بالاتر نصب کنید.
2) CMD را در این پوشه باز کنید.
3) python -m venv .venv
4) .venv\Scripts\activate
5) pip install -r requirements.txt
6) python app.py
7) مرورگر را باز کنید و وارد http://127.0.0.1:5000 شوید.

نکته: برای استفاده واقعی مدرسه، در مرحله بعد باید ورود کاربران، سطح دسترسی، پشتیبان‌گیری و امنیت را اضافه کنیم.
